# Department pilot performance rollout

This is a release gate, not a claim that the department pilot has passed it. Use synthetic, non-production data for load tests and browser artifacts.

For the latest implementation and verification status, read [progress as of 2026-10-03](2026-10-03-progress.md). The user has paused deep testing for manual UI review; outstanding release gates remain open.

## Order

1. Build backend and frontend, apply `npm run db:migrate`, then start the API and the separate material worker. Keep VT ARC credentials on the backend.
2. Release the shell, lazy routes, and read-only cached screens. Verify role navigation, cache clearing on logout, and direct route refresh.
3. Release bounded materials and dashboard lists. Check active indexing polling, terminal states, cursor continuation, and assignment grading persistence.
4. Canary streamed chat after citation and authorization regression tests. Keep the JSON chat endpoint available for rollback. If streaming fails, switch the client to JSON without enabling any external/general-knowledge answer path.

## Required measurements

Record commit, fixture sizes, machine, viewport, browser, DB version, test commands, and before/after results in a dated report. Run ordinary route load separately from generation load. Compare entry/eager bundle sizes, duplicate GETs, Web Vitals, p50/p95 route latency and errors, event-loop delay, pool waiting, chat query counts, and representative `EXPLAIN (ANALYZE, BUFFERS)` plans. Then run supported, partial, insufficient-evidence, revoked-source, and abstention examples with instructor review. A synthetic provider response does not establish answer quality.
